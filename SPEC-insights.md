# Spec: insights

Карта: [SPEC.md → Capability Map](SPEC.md#capability-map). Зависит от: `journal`.

## Objective

Найти в записях связи между привычками и самочувствием и сформулировать их честно.
Чистая статистика, **без LLM**: результат детерминирован и полностью тестируем.

## Что сравниваем

Факторы (X) → исходы (Y):

| X | Y |
|---|---|
| `sleep_hours`, время отбоя (минуты от 18:00), `morning_walk_min`, `steps`, тренировка (`workout_min > 0`) | `energy`, `mood` |

Плюс `sleep_hours` и тренировка вчера → `energy` сегодня (лаг 1 день).

## Метод

- Ранговая корреляция Спирмена (ρ) по дням, где есть и X, и Y.
- Связь показывается, только если **n ≥ 7**, **|ρ| ≥ 0.4** и пермутационный p-value
  (1000 перестановок, фиксированный seed) **< 0.05 / число проверенных пар**
  (поправка Бонферрони). Без поправки на ~12 парах при n = 7 случайный шум регулярно
  даёт «сильные» корреляции. Поэтому на первой неделе связей чаще всего не будет, и
  это честный результат.
- Для бинарных X (тренировка, прогулка да/нет) дополнительно считается разница средних Y
  «с» и «без», и только если в каждой группе ≥ 3 дней.
- Не больше 3 связей, по убыванию |ρ|.

## Интерфейс

```python
@dataclass(frozen=True)
class Insight:
    factor: str          # "morning_walk_min"
    outcome: str         # "energy"
    rho: float
    n: int
    lag_days: int        # 0 или 1
    text: str            # "В дни с утренней прогулкой энергия в среднем на 1.4 выше (n=9). Это связь, не причина."

def find_insights(entries: list[CheckinEntry]) -> list[Insight]: ...
```

Тексты собираются по шаблонам на русском. Сила связи: |ρ| 0.4–0.6 «умеренная»,
> 0.6 «сильная».

## Acceptance Criteria

1. На синтетике с заложенной связью (энергия = f(прогулка) + шум) связь находится.
2. На случайных данных при n = 7–14 хотя бы одна связь находится не более чем в 5% из 200 прогонов (фиксированный seed).
3. При n < 7 — пустой список, а UI пишет «нужно ещё N дней записей».
4. Если вариативности нет (все значения X одинаковы), функция не падает и связи не выдаёт.
5. Каждый `text` содержит n и «связь, не причина».

## Тесты

Только unit: вручную посчитанный ρ на маленьком наборе, пороги, лаг, пропуски, константные ряды.
