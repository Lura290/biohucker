# biohucker

Агент-биохакер, который разрабатывается по процессу Addy Osmani
([addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)):

```
/spec → /plan → /build → /test → /review → /code-simplify → /ship
```

| Этап | Команда | Что появляется в репозитории |
|---|---|---|
| Спецификация | `/spec <идея>` | `SPEC.md` (+ `SPEC-<модуль>.md`, если модулей несколько) |
| План | `/plan` | `plan.md`, `todo.md` — задачи, критерии приёмки, проверки |
| Сборка | `/build` или `/build auto` | код + тесты (TDD), по одному коммиту на задачу |
| Проверка | `/test` | доказательство, что всё работает |
| Ревью | `/review` | разбор по пяти осям: корректность, читаемость, архитектура, безопасность, производительность |
| Упрощение | `/code-simplify` | более простой код с тем же поведением |
| Выпуск | `/ship` | чек-лист перед запуском |

Скиллы, команды и сабагенты лежат в `.claude/` (копия agent-skills под лицензией MIT,
см. `.claude/AGENT-SKILLS-LICENSE`), поэтому Claude Code видит их сразу после клонирования.
